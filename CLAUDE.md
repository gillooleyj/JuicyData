# JuicyData (product name: JuicyCloud)

A Clippy-style cloud mascot with FedRAMP 20x humor. Personal bucket.
README.md covers build and voice details; this file is the rules.

## This repo is public
- Every line, commit message and file is visible to anyone.
- Mascot lines joke about public FedRAMP material only. Nothing internal or pre-decisional, and nothing about named people, providers or assessors.

## Layout
- `mac/`: macOS app, Swift and AppKit, single `main.swift`. Build with `cd mac && bash build.sh`.
- `ios/`: iPhone app and widget, SwiftUI and WidgetKit. The Xcode project is generated by XcodeGen from `ios/project.yml`.
- `voice/`: ElevenLabs recording script, config, and bundled clips.

## Rules
- The lines live in two places that must stay identical: `defaultLines` in `mac/main.swift` and `Lines.all` in `ios/Shared/Lines.swift`. Change both in the same commit.
- Each clip in `voice/clips/` is named by a hash of its line's text. Editing a line, even punctuation, orphans its recording.
- `python3 voice/generate.py` spends ElevenLabs credits. Run it with `--list` first, show me the character count, and ask before recording.
- The ElevenLabs key is in the macOS Keychain (`elevenlabs-api-key`). Never write it to a file or print it.
- Never edit or commit the generated `.xcodeproj`. Change `ios/project.yml` instead.
- Ask before signing, notarizing, or publishing a GitHub release.

## Verifying
- There are no tests. Verify Mac changes by building and launching `mac/build/JuicyCloud.app`.
- iPhone changes need Xcode and a Team ID. If you could not build or run something, say so.

## Related
- `~/Developer/RyanJuicyData` is a separate variant of this app. Do not copy changes between the two unless asked.
